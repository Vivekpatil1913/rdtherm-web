one page can absorb several keywords that share an intent instead of spawning a
near-duplicate.

**Rule:** do not create a separate page for every keyword. If two keywords would
be satisfied by the same answer, they point at the same URL.

## Before adding a page

1. Confirm the keyword has an intent no existing page already answers.
2. Confirm every claim on the page is sourced from published R&D Therm content
   (manufacturing data, product records, case studies, registered address).
   **Do not invent capabilities, certifications, capacity, clients or locations.**
3. Create it in the admin: **Content → SEO Landing Pages**. No code change.
4. Check it appears in `/sitemap.xml` and in the footer's Locations list.
